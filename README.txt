1. Краткое описание проекта
Разработанное веб-приложение автоматизирует процессы управления школьной столовой: включает управление меню, оформление заказов, расчёт оплат, формирование отчётности и инструменты для анализа данных. Система облегчает работу сотрудников столовой и обеспечивает удобный интерфейс для учеников и администрации.

2. Инструкция по установке:
 * Убедитесь, что у вас установлен Python 3.8 или выше.
 * Установите зависимости из файла requirements.txt:
   - pip install -r requirements.txt
